# CM1605 – Web Technology

This repository contains practice exercises, and projects completed for the **CM1605 – Web Technology** module.

## 📌 Module Overview
The module introduces modern web development concepts, focusing on building responsive and interactive websites using core web technologies.

## 🧠 Topics Covered
- HTML5 structure and semantics
- CSS3 styling and layouts
- Responsive design
- JavaScript fundamentals
- Client-side interactivity
- Basic DOM manipulation

## 💻 Technologies Used
- HTML
- CSS
- JavaScript

## 📂 Repository Structure
- Each folder corresponds to an academic week
- Projects range from static web pages to simple interactive applications

## 📚 Purpose
This repository is used to:
- Store lecture-based projects
- Practice web development concepts
- Maintain a portfolio of web-based coursework
